## 运行

```bash
cd app
npm install
npm run tauri dev     # 开发模式
npm run tauri build   # 打包成安装包
```

首次编译 Rust 依赖需要几分钟，之后增量编译约 10 秒。

## 配置

打开应用 → 设置 → 选一个预设（OpenAI / DeepSeek / 通义 / 智谱 / 月之暗面 / 本地 Ollama）→ 填 API Key → 测试连接。

- `%APPDATA%/com.verba.desktop/verba.db` — 翻译历史、术语表

## 系统集成（P2）

- **划词翻译**：任意应用里选中文本，按 `Ctrl+Alt+C`，鼠标旁弹出浮窗，译文流式输出，可一键复制或送回主窗口
- **剪贴板翻译**：`Ctrl+Alt+V` 直接翻译剪贴板内容
- **主窗口热键**：`Ctrl+Shift+D` 全局唤出 / 隐藏
- **托盘**：关闭窗口默认驻留托盘（可关），左键唤回，右键菜单直达划词 / 剪贴板翻译 / 设置 / 退出
- **复制即翻译**（可选）：后台监听剪贴板，复制即弹浮窗
- **浮窗自动复制**（可选）：翻译完成自动放回剪贴板，直接粘贴

抓词原理：备份剪贴板 → 写入哨兵值 → 模拟 Ctrl+C → 轮询剪贴板变化 → 恢复原剪贴板。抓取前会先等待并强制释放修饰键，避免热键残留污染组合键。所有热键可在设置里录制修改，冲突时会明确提示。

端到端**双击式热键**：所有热键字段都支持 `Double+X` 写法（如 `Double+C` = 快速连按两下 C，600ms 内、期间无其它按键、未按住 Ctrl/Alt/Win）。录制时在输入框里连按两下同一个键即可自动录成双击式；也可手动输入。设置页每个热键框旁有 **⌨ 按钮**，可打开虚拟键盘直接点选（双击触发 / 组合键两种模式），无需实体按键录制。写法支持 `Double+KeyC`（裸双击 C）、**`Double+Ctrl+KeyC`（按住 Ctrl 连按两下 C，推荐）**、`Double+Control`（双击 Ctrl 本身）。实现走 `GetAsyncKeyState` 全局按键状态轮询（66Hz，`src-tauri/src/keyhook.rs`），比键盘钩子更稳：不进钩子链、能感知发往管理员窗口的按键；组合键仍走 global-shortcut 插件。

回归：`python p2_test.py`（需要本地 mock，见 mock_server.py），覆盖热键 → 浮窗 → 翻译 → 入库 → 托盘驻留全链路。

## 文档翻译（P3）

侧栏「文档」页，支持 **docx / pptx / xlsx / pdf / txt / md / srt**，拖入或点选文件即可。

- **版式保留**：docx/pptx/xlsx 直接在 OOXML 包内按「段落」抽取文本 → 批量翻译 → 回写首个文本节点，样式、图片、表格、页眉页脚等部件逐字节保留，不经过任何转换器
- **PDF**：只提取文本层，输出译文 Word 文档（扫描件等 P4 OCR 接手）
- **字幕 srt**：时间轴、序号原样保留，只译正文
- **批量对齐**：段落按 1600 字符分批，用 `@@@` 分隔符对齐；模型若丢失分隔符自动逐段重译，保证不错位、不串段
- **术语表同样生效**；纯数字 / 页码域 / 公式段自动跳过
- 可随时取消（后端原子标志），输出默认 `原名.目标语言_译文.扩展名`

回归：`python make_fixtures.py && python p3_test.py`（31 项，跑真实管线：多 run 段落合并、页眉翻译、富文本单元格、内联字符串、时间轴保真、PDF→docx、非法格式拒绝等）。

## 语音翻译（P5）

`Ctrl+Alt+T`（可在设置里改）开始聆听，再按一次停止。

- **音源**：系统声音（WASAPI 回环，直接抓默认播放设备，会议/视频/播放器都行）或麦克风，不需要虚拟声卡
- **切句**两种模式：
  - **实时字幕**（默认，看剧推荐）：不等停顿，每 3 秒固定切片立即识别+翻译，字幕延迟稳定在 4 秒左右
  - 智能断句：本地 VAD，20 ms 帧能量 + 双阈值（起始高、维持低）+ 静音断句（默认 600 ms 可调），单句超 14 s 强切；识别更完整，但连续对白会攒
- **识别**两条路：
  - 接口：OpenAI 兼容 `/audio/transcriptions`，multipart 上传 16 kHz 单声道 WAV（接口地址/Key 可独立于翻译接口配置）
  - 本地命令：`whisper-cli.exe -m ggml-base.bin -f {file} -nt` 这类写法，`{file}` 替换为临时 WAV 路径，标准输出即识别结果，完全离线
  - **一键配置**：设置 → 语音 → 「一键配置本地识别」，可选 tiny（77MB·最快）或 base（142MB·较准），自动下载 whisper.cpp 官方程序与模型到应用目录并填好命令（下载走国内镜像 hf-mirror + gh-proxy）。实测 tiny 识别 11 秒英文语音 0.85s 出结果
- **翻译**：快速档模型流式输出，术语表同样生效；字幕窗为透明置顶 + 鼠标穿透，悬浮在屏幕底部
- 主窗口「语音」页有实时音量表、逐句原文/译文列表，可复制全文或导出 txt

回归：`python p5_test.py`（热键 → 回环抓 440 Hz 音调 → WAV 上传 → mock 识别/翻译 → OCR 核对字幕渲染 → 停止后字幕隐藏）。

## 截图翻译（P4）

`Ctrl+Alt+S`（可在设置里改）→ 全屏覆盖窗拖拽框选 → 本地 OCR → 浮窗流式译文。

- **OCR 用 Windows 自带的 Windows.Media.Ocr**，完全离线、不上传截图；精度取决于系统语言包（简中/英文开箱即用，其它语种在 设置 → 时间和语言 → 语言 → 可选功能 里补装）
- 先抓全屏图再显示覆盖窗，选完从已抓图里裁剪——窗口自身永远不会被拍进结果
- 选区结果面板出现在选区正下方（放不下自动翻到上方），可查看原文、复制译文、重截；Esc 关闭
- 中文识别结果里字与字之间的空格会被自动合并；按行距聚合段落
- 「文档」页也支持直接拖入 **png / jpg / bmp / webp**：本地 OCR → 整段翻译 → 输出 txt

回归：`python p4_test.py`（端到端：热键 → 覆盖窗 → 拖拽 → OCR 入库 → mock 翻译 → 结果面板 → Esc 关闭）。测试用临时 PowerShell 窗体当 OCR 靶子，测完自动还原 settings.json。

## 双档流水线

这是实测出来的设计，不是拍脑袋：

1. 打字时先用**预览模型**（快、便宜）出译文，首字延迟低
2. 停顿 700 ms 后，用**精修模型**带着初稿再译一遍，覆盖显示

实测数据（20 句跨五域盲评）显示：快档模型单条最优次数最多但方差大，会把术语占位符原样抄进译文；精修档更稳但会弱化法律语态。两档组合才既快又稳。

## 术语表

术语在翻译时注入 system prompt，译后做正则校验，未命中会在译文栏上方提示。

注意：含「……」的模板型术语不能整条注入，会被模型当成字面内容抄进译文——这类要拆成前后缀两条规则。
